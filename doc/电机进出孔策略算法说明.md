## 2. 进出孔速度策略 —— 三段式 S 形替代曲线

### 2.1 核心设计思想

为避免电机在进孔时高速撞击，系统采用**三段式降速策略**，在位置环输出与最终速度设定点之间插入一个**距离线性限速层**，实现从全速到慢速的平滑过渡。

### 2.2 速度分段图解

```
PWM速度
  ^
  │
force ─────┐                    ← 全速段
  │         \  ┐                ← S曲线缓冲段 (force→time_c 平滑降速)
  │          \  │
  │           \ │
  │            \│
  │             └───────────    ← 位置环PID自然减速至光电触发
  │            │
  │            │
  └────────────┼────────────→ 距目标距离(pulse)
        pulse_buf   0(目标)
        (30000)
```

> **策略变更 (2026-07-04)**: 正常切换孔位全程使用双环控制（`run_flag=1`），不再在 `pulse_low` 处切换到单环慢速段。
> 位置环PID在接近目标时自然减小输出，配合S曲线缓冲段限速，实现平滑进孔。
> `run_flag=2/3`（单环慢速）仅用于补偿调整路径（欠冲/过冲/过孔位回转）。

### 2.3 分段执行逻辑 (详见 `atim.c:225-313` TIM6 ISR)

系统使用 `run_flag` 状态机控制速度分段：

| run_flag | 含义 | 速度策略 | 触发条件 |
|----------|------|----------|----------|
| `0` | 空闲 | 电机停止 | 默认 |
| `1` | 正常切换 | 位置环PID → S曲线限速 → 速度环PID (全程双环) | 正常孔位切换启动 |
| `2` | 正向慢速补偿 | 恒定速度 `+time_c` (单环) | 欠冲/过冲补偿(正转方向) |
| `3` | 反向慢速补偿 | 恒定速度 `-time_c` (单环) | 欠冲/过冲补偿(反转方向) |

> `run_flag=2/3` 由 `step_motor_motion()` 中的补偿路径显式设置，不再由 ISR 自动从 `run_flag=1` 切换。

### 2.4 缓冲段距离线性限速算法

**核心代码** (`atim.c:281-291`):

```c
// run_flag == 1 时执行
float dist = (location < SetPoint_P)
    ? (SetPoint_P - location)      // 正转: 剩余距离
    : (location - SetPoint_P);     // 反转: 剩余距离

// 仅当 dist 在 (pulse_low, pulse_buf) 区间内时限速
if (dist < (float)pulse_buf && dist > (float)pulse_low && pulse_buf > pulse_low)
{
    // ratio: 0(靠近pulse_low端) → 1(靠近pulse_buf端)
    float ratio = (dist - (float)pulse_low) / ((float)pulse_buf - (float)pulse_low);

    // limit: time_c(ratio=0, 接近慢速段) → force(ratio=1, 接近全速段)
    float limit = (float)time_c + ((float)force - (float)time_c) * ratio;

    // 用 limit 钳位位置环输出
    int32_t ilimit = (int32_t)limit;
    if (motor_pwm >  ilimit) motor_pwm =  ilimit;
    if (motor_pwm < -ilimit) motor_pwm = -ilimit;
}
SetPoint_S = motor_pwm;  // 限速后的值作为速度环目标
```

**算法推导**:

给定:
- $V_{max} = F$ (全速)
- $V_{slow} = V$ (慢速)
- $D_{buf} = BS$ (缓冲起始距离)
- $D_{low} = S$ (慢速起始距离)
- $d$ = 当前位置距目标距离

限速值 $L(d)$ 的计算:
$$ratio(d) = \frac{d - D_{low}}{D_{buf} - D_{low}}$$
$$L(d) = V_{slow} + (V_{max} - V_{slow}) \times ratio(d)$$

当 $d = D_{buf}$ (进入缓冲区): $ratio=1$, $L = V_{max}$ (全速)
当 $d = D_{low}$ (离开缓冲区): $ratio=0$, $L = V_{slow}$ (慢速)

### 2.5 完整运动速度剖面

```
阶段          run_flag  速度指令来源          距离范围
─────────────────────────────────────────────────────
全速段           1      位置环PID(限幅force)    > pulse_buf
S曲线缓冲段       1      位置环PID + smoothstep限速  (0, pulse_buf]
接近目标段        1      位置环PID直接输出       光电触发即停止
```

> **正常切换**: 全程 `run_flag=1`，位置环PID在接近目标时误差趋近于零，输出自然减小，
> 配合 S曲线缓冲段限速，电机平滑进孔直至光电传感器触发。
>
> **补偿调整** (欠冲/过冲/过孔位): 使用 `run_flag=2/3`，以恒定慢速 ±`time_c` 微调位置。

## 3. PID 级联控制架构

### 3.1 双环级联结构

```
位置指令 ──→ [位置环PID] ──→ SetPoint_S ──→ [速度环PID] ──→ PWM ──→ 电机
  SetPoint_P    ↑                           ↑                    │
                │ 位置反馈(location)          │ 速度反馈(speed_m)  │
                └────── 编码器(TIM3) ────────┴──── 速度计算 ──────┘
```

### 3.2 位置环 (Position PID)

- **类型**: 位置式 PID (`position_pid_speed()`)
- **输入**: `SetPoint_P` (目标位置) - `location` (当前位置)
- **输出**: 目标速度 `SetPoint_S` (经限幅和限速后)
- **积分限幅**: ±40000
- **PID 参数** (默认): KP=0.03, KI=0.005, KD=0.0

### 3.3 速度环 (Speed PID)

- **类型**: 增量式 PID (`increment_pid_speed()`)
- **输入**: `SetPoint_S` (目标速度) - `speed_m` (当前速度)
- **输出**: `motor_pwm` (PWM 占空比值)
- **限幅**: ±force_F
- **PID 参数** (默认): S_KP=3.0, S_KI=0.3, S_KD=0.0

### 3.4 速度测量与滤波

速度计算在 `speed_computer()` (`step_motor.c:728-782`) 中实现:

1. **采样**: 每 5ms 读取一次编码器差值
2. **滑窗滤波**: 连续采集 10 个速度样本
3. **冒泡排序**: 对 10 个样本排序
4. **中值平均**: 取中间 6 个值 (丢弃最大2个和最小2个)
5. **一阶低通滤波**: $Y_n = 0.48 \cdot X_n + 0.52 \cdot Y_{n-1}$

### 4.2 光电传感器消抖

```c
int ele_is_triggered(void) {
    if (HAL_GPIO_ReadPin(ST1_ELE_GPIO_PORT, ST1_ELE_GPIO_PIN) == 0) {
        delay_ms(10);  // 10ms 消抖
        if (HAL_GPIO_ReadPin(ST1_ELE_GPIO_PORT, ST1_ELE_GPIO_PIN) == 0) {
            return 1;  // 确认触发
        }
    }
    return 0;
}
```

### 4.3 光电检测窗口

光电检测不是全程开启的，只有当编码器位移超过 `pluse_ele` 后才开始检测：

```c
// 正转 (step_motor.c:150-172)
if (Encode_now > SetPoint_C + pluse_ele) {
    if (ele_is_triggered()) {
        // 检测到光电 → 停止, 记录脉冲数
        SetPluse = Encode_now - SetPoint_C;
        motor_stop_normal();
    }
}
```

设置该窗口的目的是**避免起始位置就在光电传感器范围内导致的误触发**。

### 4.4 位置微调策略 (过孔未触发光电)

当电机运动到目标位置 (`Encode_now` 接近 `SetPoint_P`) 但光电传感器未触发时，系统会进行微调:

```
光电未触发
    │
    ├── 位置 < SetPoint_P - 300:  继续前进 (run_flag=2)
    │                             直到光电触发或超时
    │
    └── 位置 > SetPoint_P + 300:  继续前进 (run_flag=3)
                                  直到光电触发或超时

    (反转时逻辑对称相反)
```

微调使用 `run_flag=2`（正向）或 `run_flag=3`（反向），即恒定慢速运动。

## 5. 路径规划 —— 最短路径方向决策

### 5.1 算法原理 (`dir_jud()`)

5个工位圆形排列，计算两个方向哪个更短：

```c
int dir_jud(int target_num, int current_num) {
    int fwd = (target_num - current_num + 5) % 5;  // 正转步数 (0~4)
    if (fwd <= 2) {
        return 0;  // 正转 ≤ 2步, 走正转
    } else {
        return 1;  // 正转 > 2步(即3或4步), 走反转更短
    }
}
```

**示例**:

| 当前位置 | 目标位置 | fwd | 方向 | 说明 |
|:--------:|:--------:|:---:|:----:|------|
| 1 | 2 | 1 | 正转(0) | 正转1步 |
| 1 | 3 | 2 | 正转(0) | 正转2步 |
| 1 | 4 | 3 | 反转(1) | 反转2步更短 |
| 1 | 5 | 4 | 反转(1) | 反转1步更短 |
| 3 | 1 | 3 | 反转(1) | 反转2步 |

### 5.2 多站跳转 (`step_motor_LX()`)

跳转到指定工位时，每次前进一站，最多尝试5次：

```c
void step_motor_LX(int target_num, int dir) {
    int i = 0;
    while (1) {
        i++;
        if (i > 5) break;  // 最多5次防止死循环
        step_motor_motion(1, dir);  // 运动一站
        wait_motion_done();
        station_x = read_hal();     // 读取霍尔确认位置
        if (target_num == station_x) break;  // 到达目标
    }
}
```

霍尔读取使用**5次采样多数表决消抖** (`read_single_hal()`):

```c
static int read_single_hal(GPIO_TypeDef *GPIOx, uint16_t GPIO_Pin, int weight) {
    int sum = 0;
    for (int i = 0; i < 5; i++) {
        sum += HAL_GPIO_ReadPin(GPIOx, GPIO_Pin);
        delay_ms(10);
    }
    return (sum >= 3) ? weight : 0;  // 5取3多数表决
}
```

## 7. 电机初始化策略 (`motor_init()`)

初始化流程用于将电机对准到一个已知位置（光电传感器遮挡位置）：

```
开始
  │
  ├── 光电 == 1 (未遮挡)?
  │     → 已经在孔外, 无需初始化, printf_flag=1
  │
  └── 光电 == 0 (遮挡中)?
        │
        ├── error == 1? → 报错退出
        │
        └── error == 0?
              │
              ├── 步骤1: 正转找光电下降沿
              │     (光电从0→1, 即从遮挡变为不遮挡)
              │     找到 → 停止
              │
              ├── 步骤2 (备选): 再找一次光电触发
              │     如果步骤1未成功
              │     找到 → 停止
              │
              └── 两次均失败? → alarm=8, error=1
```

核心代码逻辑 (`step_motor.c:427-521`):
```c
// 找光电下降沿: 从孔内到孔外
if (HAL_GPIO_ReadPin(ST1_ELE_GPIO_PORT, ST1_ELE_GPIO_PIN) == 1) {
    delay_ms(10);
    if (HAL_GPIO_ReadPin(ST1_ELE_GPIO_PORT, ST1_ELE_GPIO_PIN) == 0) {
        motor_stop_normal();
        break;
    }
}
```

## 8. 安全保护机制

### 8.1 多层保护体系

| 保护层 | 检测机制 | 响应时间 | 动作 |
|--------|----------|----------|------|
| 24V断电 | PF7 下降沿中断 + 轮询 | <1ms (中断) / <主循环周期 | 立即停止 + error=1 |
| 运行超时 | TIM5 (0.5s中断), time_out>8 | ~4s | 停止 + alarm=4 |
| 过孔超限 | 编码器位置 > 目标+5000 | <PID周期 (20ms) | 停止 + alarm=10 |
| 光电异常 | 位移>1000但光电未触发 | <PID周期 | error=1 + alarm=3 |
| 工位验证失败 | 霍尔读数不符合预期 | 运动结束后 | alarm=9/7 |

### 8.2 急停时序

```
24V断电检测 (IN2=0)
  │
  ├── dcmotor_stop()     // 关断电机使能
  ├── motor_pwm_set(0)   // PWM 清零
  ├── run_flag = 0       // 清除运行标志
  ├── run_printf_flag = 0
  ├── HAL_TIM_Base_Stop_IT(&TIM5_Handler)  // 停止超时计时
  └── error = 1          // 置错误标志
```

### 8.3 复位信号

IN1 上升沿自动清除 `error` 标志（软复位，见 `main.c:230-234`）:

```c
if (in1_now == 1 && in1_last == 0) {  // 上升沿
    printf("复位信号,报警清除!\r\n");

}
```

## 11. 调参指南

### 11.1 速度相关参数联动关系

```
force (最大速度)
  │
  ├── 影响: 全速段运动速度
  ├── 调大: 运动更快, 但超调风险增大
  └── 调小: 运动更平稳, 但时间更长

time_c (进孔速度)
  │
  ├── 影响: 最后进入孔位时的恒定速度
  ├── 调大: 进孔更快, 但可能撞击
  └── 调小: 进孔更柔和, 但可能因摩擦力停转

pulse_low (慢速段脉冲数)
  │
  ├── 影响: 以低速运动的距离
  ├── 调大: 更早开始减速, 进孔更安全
  └── 调小: 更晚减速, 但进孔可能不稳

pulse_buf (缓冲段脉冲数) [必须 > pulse_low]
  │
  ├── 影响: 减速斜坡的跨度
  ├── 调大: 减速更平缓 (斜率更小)
  └── 调小: 减速更急促 (斜率更大)
```

### 11.2 PID 参数调优

| 参数 | 增大效果 | 减小效果 |
|------|----------|----------|
| **KP** (位置环P) | 响应更快, 可能振荡 | 响应慢, 更稳定 |
| **KI** (位置环I) | 消除静差更快, 可能过冲 | 静差消除慢 |
| **KD** (位置环D) | 抑制超调, 可能放大噪声 | 超调更大 |
| **S_KP** (速度环P) | 速度跟踪更快 | 速度响应慢 |
| **S_KI** (速度环I) | 速度静差小 | 可能速度偏差大 |
| **S_KD** (速度环D) | 抑制速度振荡 | 可能有速度过冲 |

### 11.3 典型问题排查

| 现象 | 可能原因 | 建议调整 |
|------|----------|----------|
| 进孔撞击声大 | 进孔速度过高 | 减小 `V`(time_c), 增大 `S`(pulse_low) |
| 过孔不停/超限 | 光电传感器未触发 | 检查光电安装, 增大 `E`(pluse_ele) |
| 到位后晃动 | 位置环P过大 | 减小 `KP` |
| 运动无力/慢 | 占空比限制过低 | 增大 `R`(force_F) |
| 减速过程振荡 | 缓冲段跨度过大 | 减小 `BS`(pulse_buf) 或调PID |
| 工位验证失败 | 霍尔传感器偏移 | 检查机械安装, 调整微调逻辑 |
