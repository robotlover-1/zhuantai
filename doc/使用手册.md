# 平式步进电机控制系统 — 使用手册

## 1. 概述

本项目基于 **STM32F407ZG** 微控制器，通过定时器产生脉冲驱动步进电机，实现 5 个工位间的精确定位。支持工位跳转、回零、拍照触发、补偿控制、疲劳/自动测试、参数 Flash 存储等功能。

系统为**开环步进控制**（无编码器闭环），定位精度依赖步进电机不失步以及补偿（过冲回退）消除减速箱齿轮回差。

### 1.1 硬件资源

| 外设 | 功能 | 参数 |
|------|------|------|
| **MCU** | STM32F407ZG | 168 MHz |
| **TIM1** | 电机脉冲输出（PWM 翻转模式） | 2 MHz 基础时钟 |
| **TIM5** | 运动计时 | 4 Hz |
| **UART5** | 主串口（命令交互，PC 串口终端） | 115200 baud, 8N1 |
| **UART4** | 从串口（向拍照设备发送指令） | 9600 baud, 8N1 |

### 1.2 引脚定义

#### 输出引脚

| 信号 | 引脚 | 说明 |
|------|------|------|
| 电机使能 (EN) | PC1 | 开漏输出，控制电机使能 |
| 方向 (DIR) | PA11 | 推挽输出，控制电机方向 |
| 回零信号 (ZERO) | PC0 | 开漏输出，低电平触发外部回零 |
| 拍照 (IO) | PC5 | 推挽输出，触发相机拍照 |
| 到位脉冲 (DONE) | PC4 | 推挽输出，运动到位脉冲 |
| 报警信号 (ALARM) | PC2 | 开漏输出，运动超时报警时输出 50ms 高电平脉冲（外部上拉输出 24V），对齐 F1 |

#### 输入引脚

| 信号 | 引脚 | 说明 |
|------|------|------|
| 回零完成检测 (HOME) | PF8 | 回零完成信号输入，外部上拉，回零完成时被拉低 |
| 24V 输入 1 (IN1) | PF6 | 正转信号输入（低电平触发） |
| 24V 输入 2 (IN2) | PF7 | 急停信号输入（低电平触发，下降沿中断响应，运动期间立即生效） |
| 复位输入 | PE2 | 复位信号（低电平清除报警并解除急停锁定） |
| 霍尔 1/2/3 | PE5 / PE6 / PC13 | 仅调试用 |

> 注：原 PF9（光电到位检测）已取消，未接入硬件。

### 1.3 IO 控制说明

#### 工作前提：24V 电源

IO 信号通过**双向光耦**与 MCU 隔离。使用 IO 输入（正转/急停）或 IO 输出（到位/报警）前，必须先在 IO 连接器 **引脚 1（24V 正）、引脚 2（24V 负）** 接通 24V 电源——这是光耦输入侧的工作电源，也是 24V 输出的上拉电源。未接 24V 时，光耦输入无法驱动，所有 IO 控制失效。**正负极不可接反。**

#### IO 连接器引脚 ↔ MCU 引脚对应

| 连接器引脚 | 功能 | MCU 引脚 | 说明 |
|:---:|------|---------|------|
| 1 | 24V 供电正 | — | 光耦输入侧电源 |
| 2 | 24V 供电负 | — | 电源回路 |
| 3 | 到位信号（输出） | PC4 | 运动完成输出 100ms 高脉冲 |
| 4 | 报警信号（输出） | PC2 | 运动超时报警输出 50ms 高脉冲 |
| 5 | 复位（输入） | PE2 | 低电平触发，解除急停锁定并清报警 |
| 6 | 急停（输入） | PF7 | 24V 脉冲（约 20ms），下降沿中断立即停电机 |

> 注：正转（PF6）同为板载 24V 光耦输入（24V 信号输入 1），不在上述连接器引脚定义内（对应预留引脚或板内接线）。

#### "施加 24V" 的含义：物理电气动作，不是串口命令

"给引脚施加 24V"指通过**按钮、继电器或 PLC 触点**把信号引脚接通到 24V 电源（引脚 1），使引脚与 24V 短接——固件经光耦感知电平变化后执行对应动作。这**不同于串口命令**（通过串口发送 `RTF`/`D0`/`L1~L5` 等文字指令），两者是独立通道，效果等价。

| 控制方式 | 通道 | 动作 |
|---------|------|------|
| 串口命令 | 串口线发文字 | 发送 `"RTF\r\n"`、`"D0"` 等 |
| IO 信号 | 12 脚 IO 连接器 | 按钮/继电器/PLC 触点把引脚接通到 24V |

#### 三个 IO 输入的用法

| 功能 | MCU 引脚 | 触发方式 | 作用 |
|------|---------|---------|------|
| 正转 | PF6 | 施加 24V（轮询检测，约 50ms 周期） | 前进一个工位 |
| 急停 | PF7 | 施加 24V 脉冲（约 20ms，下降沿中断） | 立即停止电机并锁定 |
| 复位 | PE2 | 拉低电平（接地） | 解除急停锁定、清报警 |

> 注：正转/急停是 **24V 高电平**触发（光耦输入）；复位 PE2 是普通 GPIO，**低电平（接地）**触发，不接 24V。

#### 急停接线示例

```
IO 引脚6（急停信号） ──按钮── IO 引脚1（24V 正）
IO 引脚2（24V 负） ───────── GND
```

按下按钮约 20ms → 引脚 6 变 24V → 光耦将 PF7 拉低 → 急停生效（停止电机并锁定）。急停后需给 PE2 发复位信号解锁，再通过串口执行 `D0` 回零、`L1~L5` 切换工位。

#### 三个 IO 的使用流程

1. 接通 IO 接口 24V 电源（引脚 1 正、引脚 2 负）——IO 生效前提
2. 正转：给 PF6 施加 24V → 转台前进一个工位
3. 急停：给 PF7 发 24V 脉冲（≈20ms）→ 立即停电机并锁定
4. 复位：给 PE2 发低电平（接地）→ 解除锁定、清报警
5. 复位后通过串口（`D0` 回零 / `L1~L5` 切工位）继续操作

## 2. 连接方式

使用 **USB 转 TTL 串口模块** 连接 PC 与设备：

| 串口模块 | 设备端 (UART5) |
|----------|----------------|
| TX | PD2 (UART5 RX) |
| RX | PC12 (UART5 TX) |
| GND | GND |

> **波特率**：115200, 8N1, 无流控

打开串口终端软件（如 SecureCRT、Putty、串口助手等），连接对应 COM 口，设置波特率 115200。

所有命令以回车（`\r\n`）结尾发送。

### 3.5 固件升级（IAP）

系统采用 **bootloader + APP 双程序**架构，实现现场串口升级：

| 程序 | 地址 | 说明 |
|------|------|------|
| bootloader | 0x08000000（64KB） | 检查升级标志，XCOM 裸字节接收固件写入 APP 区 |
| APP | 0x08010000（320KB） | 现有电机控制程序 |
| 参数区 | 0x08060000（Sector7） | 升级时不动，参数保留 |

**升级流程（用 XCOM 串口助手）：**

```
1. 电脑串口连 UART5（115200），打开 XCOM
2. 发 RES 命令 → APP 保存参数、写升级标志 1、软复位
3. 进入 bootloader → 打印 "BOOT: waiting bin, XCOM send file now..."
4. XCOM 点"发送文件"，选 test.bin（直接发裸字节，不加任何转换）
5. 收完（空闲 1 秒判结束）→ 校验向量表 → 写 Flash → 清标志 → 跳回 APP
6. APP 启动，参数保留
```

> **固件大小限制**：≤96KB（先收进 RAM 再写 Flash，避免写入期间丢字节）。当前固件约 33KB。

**异常处理：**

| 情况 | 行为 |
|------|------|
| 传输一半断电 | 升级标志保持 1，再上电仍进升级模式，可重试 |
| 文件损坏/缺字节 | 裸协议无校验，写完后验证向量表无效 → 留在 bootloader 重发 |
| 传输中止 | 空闲 1 秒判结束；固件无效则留在 bootloader 重发 |

**首次量产：** 用 ST-Link/J-Link 烧 bootloader（boot.hex），之后升级只走 XCOM 发 test.bin，bootloader 无需重烧。

## 4. 补偿机制说明

系统为**减速比 60 的齿轮箱**，齿轮之间存在回差（间隙），会导致正/反向进入同一工位时定位偏差。

| 模式 | 行为 | 精度 |
|------|------|------|
| `B:0`（补偿） | 先正向过冲 `C:` 脉冲，再反向回退，使齿轮咬合在固定一侧 | 高，可重复 |
| `B:1`（一步到位） | 直接走目标距离，不过冲不回退 | 省时，但受回差影响精度下降 |

- 需要高精度定位时，使用 `B:0`（默认）
- 需要快速移动、可接受一定偏差时，使用 `B:1`

## 6. 注意事项

1. **回零**：`D0` 通过 PC0 输出低电平触发外部驱动器回零，随后做正反向补偿并标记为工位 1（P1）。回零依赖外部驱动器的 HOME 功能。
2. **急停保护**：IN2（PF7）低电平时由下降沿中断立即停止电机——运动期间主循环忙等（`RTF`/`RTB`/`D0`/测试）也能响应。停止脉冲输出并置 `reset_flag` 锁定，拒绝一切运动命令；解除锁定需 IO 复位（PE2 低电平）或 `RES` 软复位。
3. **复位信号**：PE2 低电平时清除 `error`/`time_out`/`g_zero_flag` 并解除急停锁定（清 `reset_flag`）。急停后必须先复位，才能再次回零或切换工位。
4. **报警信号**：运动超时（TIM5 约 20 秒无步进）触发报警——置 `error` 标志，PC2（24V 输出 2）输出 50ms 高电平报警脉冲（对齐 F1）。`CLC` 命令或复位信号清除。
5. **参数保存**：所有参数命令设置后自动保存到 Flash（Sector 7, 0x08060000），断电不丢失。`RES` 会先保存参数再复位。
6. **运动计数**：`CYCLE` 查询总运动次数，`CC` 清零。每满 1000 次自动保存一次（减少 Flash 擦写）。
7. **负载运行**：加负载后如出现丢步（定位偏移、测试卡死），优先检查驱动器电流是否调到电机额定电流，并考虑降低 `J:`/`L:`（加速度）和 `D:`（最大速度）。
8. **测试卡死保护**：gnn/goo 测试中运动超时 20 秒会自动复位并继续，拍照发送超时 100 ms 会自动跳过，避免卡死。
9. **RTC**：系统启动时从编译时间初始化 RTC，断电后需重新设置。

| 功能 | 说明 |
|------|------|
| **补偿开关** | F1 固定为「顺时针不补偿、逆时针补偿」；F4 通过 `B:` 命令自由切换「全补偿（精度高）/一步到位（省时）」 |
| **最短路径** | `B:1` 模式下 L1~L5 跳转使用最短路径（双向选择，最多 2 步）；F1 只有固定方向 |
| **12 小时测试** | `PL`/`CS` 命令使用独立参数（PLT/PLH、CST/CSH），不覆盖 T/H，适合长时间磨合/寿命测试 |
| **运动计数** | 记录总运动次数，每满 1000 次自动保存一次到 Flash（减少擦写），可查询（`CYCLE`）和清零（`CC`） |
| **参数统一保存** | 所有参数命令设置后自动保存到 Flash；F1 部分参数仅当次生效 |
| **测试卡死保护** | 运动等待 20 秒超时自动复位、拍照发送 100 ms 超时自动跳过，防止长时间运行卡死 |
| **拍照触发升级** | `OP`/`goo` 拍照同时输出 PC5 脉冲并发送 UART4 指令（F1 仅发送串口指令） |

### 7.3 行为变化

| 项 | F1 | F4 |
|----|-----|-----|
| 回零 `D0` | PC2 置高 1 秒触发 + 等待光电到位 | PC0 输出低电平触发外部驱动器回零 + 固定延时 + 补偿 |
| 光电检测 `ELE` | 读取光电传感器（PE4/PC7） | 读取回零完成检测（PF8，HOME） |
| 急停 | GPIOE PIN4 硬件检测（打印 E4 被注释） | PF7 下降沿中断检测（运动期间立即生效，`reset_flag` 锁定），打印 `IO:RTS` |
| 拍照 | 仅串口发送 `OP` | PC5 脉冲 + 串口发送 `OP` |
| 计数查询 | `RED`（读 Flash 循环数）/ `CLE`（清零） | `CYCLE` / `CC` |
| 串口分工 | UART2/UART3 用于交互与拍照 | UART5 交互、UART4 拍照 |
