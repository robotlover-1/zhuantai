# 设计：复位改到 PF6（移除正转 IO 触发与 PE2 复位）

> **日期**: 2026-08-26 | **项目**: new (STM32F407 步进电机控制) | **分支**: feature/iap-bootloader

## 1. 目标

把**复位**功能从 PE2 移到 **PF6**。PF6 原为"正转 IO 触发"，本改动将其改为复位输入；**正转 IO 触发移除**（串口 `RTF`/`RTB` 命令保留）；**PE2 复位逻辑整体删除**（PE2 不是 24V 光耦输入，原复位用途错误）。PF7 急停不变。

## 2. 现状

| 功能 | 引脚 | 触发 | 处理方式 |
|------|------|------|----------|
| 正转触发 | PF6 | 24V 输入（光耦），低电平 | 主循环轮询 → `cmd_rtf()` |
| 急停 | PF7 | 24V 输入（光耦），低电平，下降沿中断 | 中断 + 轮询 → 停电机 + `reset_flag=1` |
| 复位 | PE2 | 普通 GPIO，低电平（接地） | 主循环轮询 → 清 error/解除急停锁定 |

用户确认：`key.c`（PE2/PE3 按键）未接入主流程；PE2 为普通 GPIO 而非 24V 输入，复位应改在 PF6 这个 24V 光耦通道上。

## 3. 改动设计

### 3.1 `step_motor.c` — 引脚初始化（L83-107）

- **PF6**（L87-93）：注释由"24V输入1 正转触发 (轮询)"改为"24V 输入 复位 (轮询)"。GPIO 配置不变（`GPIO_MODE_INPUT` + `GPIO_PULLUP`）。
- **PE2**（L104-107）：删除 `gpio_init_struct.Pin = GPIO_PIN_2` 的初始化块。
- L85 `__HAL_RCC_GPIOE_CLK_ENABLE(); /* PE2: 复位输入 */`：删除（GPIOE 时钟已由 HAL1/HAL2 的 `ST1_HAL1/HAL2_GPIO_CLK_ENABLE` 使能，冗余）。
- PF7（L94-102）急停配置：**不变**。

### 3.2 `main.c` — IO 轮询（L152-175）

- **PF6 块**（L153-156）：改为复位逻辑（即原 PE2 块内容）：
  ```c
  if (HAL_GPIO_ReadPin(GPIOF, GPIO_PIN_6) == 0) {      /* PF6: 复位 (LOW有效) */
      time_out = 0;
      error = 0;
      g_zero_flag = 0;
      reset_flag = 0;            /* 解除急停锁定 */
      alarm_set(0);              /* 清除报警输出 */
  }
  ```
  不再调用 `cmd_rtf()`，不再打印 `IO:RTF`。
- **PE2 块**（L169-175）：删除。
- PF7 急停块（L157-168）：**不变**。

### 3.3 串口命令保留

`cmd_rtf`/`cmd_rtb` 及 `RTF`/`RTB` 串口分发（cmd_handler.c）**不改**。`cmd_rtf` 仍被串口命令引用，无死代码。

### 3.4 文档同步（仅 new 项目）

- `doc/使用手册.md`：L37、L39、L60、L63、L78、L80、L82、L91、L96-98、L348-349 —— PF6 由"正转触发"改为"复位输入"；PE2 复位表述删除/标注未用。
- `doc/README.md`：L44、L46、L296、L298 —— 同上；L388"PF6/PF7 上拉"表述仍成立（两脚仍为 24V 输入），仅需微调措辞。

> `doc/电机进出孔策略算法说明.md` 描述另一套架构，不修改。

## 4. 验证方案

1. **编译**：Keil MDK 工程正常编译通过。
2. **真机**（建议用户执行）：
   - PF6 施加 24V → 复位生效：清 `error`/`time_out`/`g_zero_flag`、解除急停锁定（`reset_flag=0`）、清报警。
   - PF7 施加 24V → 急停仍立即生效（停电机 + 锁定）。
   - 串口 `RTF` 仍能正转一个工位；`RTB` 反转正常。
   - 急停后先用 PF6 复位解锁，再执行 `D0`/`L1~L5`。

## 5. 影响与风险

- **行为变化**：正转不再支持 IO 触发（只能串口 `RTF`）；复位从 PE2（普通 GPIO 接地）改为 PF6（24V 光耦，施加 24V 触发）。触发方向不变（都是低电平生效）。
- **复位触发方式差异**：PE2 原为接地拉低；PF6 为 24V 光耦输入，需施加 24V（与急停/原正转一致）。接线需按新定义。
- **范围**：仅 new 项目；F1 项目不在本次改动内。
